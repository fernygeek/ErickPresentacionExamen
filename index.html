Contexto del proyecto

Objetivo del sistema

El proyecto cleaning-crud administra productos de limpieza mediante una API REST y una interfaz web estática. Implementa operaciones CRUD, estadísticas de inventario e integración HTTP con un gestor de eventos.

+

Base funcional sólida: CRUD completo, persistencia SQLite, validaciones, logs, pruebas unitarias y emisión de eventos.

Requerimiento principal

Construir un CRUD robusto, observable y seguro, partiendo de un CRUD inicial y aplicando los cuatro tipos de mantenimiento de software.

  • Instrumentación obligatoria de pruebas unitarias.
  • Logs estructurados de auditoría.
  • Documentación estandarizada de API.
  • Protección por API Key y configuración externa.
